# Reference profile — nextlevelok.com

Generated by `harness/profile.mjs` (28 passes, 0 failures) and `harness/motion.mjs`.
Raw traces: `.harness/profile/*.json`, `.harness/motion/*.json`. Never `cat` them.

## 0. Access

- **No bot wall.** `https://www.nextlevelok.com` returns 200 to headless Chromium with a
  normal UA, on every page profiled. No Cloudflare interstitial, no 403, no geo gate, no
  auth. The headed-retry / local-copy fallback in Appendix A was **not** needed.
- Platform: **Duda** (`SiteType: DUDAONE`, `SystemID: US_HIBU_PRODUCTION`), Duda "Flex"
  sections. Section unit is `section.flex-element.section`; that selector is what the
  harness measures.
- 7 of ~14 stylesheets are cross-origin and unreadable from script (`sheetsBlocked: 7`).
  Media-query extraction therefore covers same-origin CSS only — 1094 rules read. The
  breakpoints below are consistent across all seven pages, so the sample is sufficient.

**The reference is a roofing company, not a garage-door company.** We clone its design
system, layout, density, and interaction patterns; the trade, the copy, and the business
facts are ours. That is by design (D-09/D-10), and it is why almost nothing on our side
can be honestly classified FIDELITY once Prompt 3 lands.

## 2. Breakpoints in the CSS

Distinct same-origin media queries, home page (14; the other pages are a subset):

```
(max-width: 600px)            only screen and (max-width: 600px)
(max-width: 767px)            (min-width: 0)   and (max-width: 767px)
(max-width: 768px)            (min-width: 0px) and (max-width: 767px)
(max-width: 1024px)           (max-width: 1024px) and (min-width: 768px)
(min-width: 600px)            (min-width: 768px)
(min-width: 768px) and (max-width: 1024px)
(min-width: 769px)            (min-width: 1025px)            all
```

Effective device tiers: **≤767 mobile, 768–1024 tablet, ≥1025 desktop**, with a minor
600px sub-break for type. Per the cost rule, we capture and diff **BP_SET = 390 / 768 /
1440** only. 600 and 1024/1025 are recorded here and are *not* extra capture axes. 430 is
profiled (not diffed) because it is the real iPhone Pro Max width for a phone-call-driven
business; at 430 the layout is identical to 390 (home 9493 vs 9503 — a 0.1% delta), so it
adds nothing to the diff set. **This is the note the process asks for: the reference CSS
has five breakpoints and we are deliberately capturing three.**

Header height is the clearest responsive tell: **177px @390 · 96px @768 · 224px @1440**.
Content container: ~359 @390, ~707–737 @768, ~1325 max with a ~958 text column @1440.

## 3. Motion — time-driven, not scroll-linked

`harness/motion.mjs`, rAF-sampled at 3px/frame across the full page (2112 frames @1440,
2752 @390; ~530 and ~690 samples). Verdict at both widths:

**TIME-DRIVEN — discrete state changes only. No scroll choreography.**

- `continuous: 0` — not one watched element changes transform or opacity as a continuous
  function of scrollY.
- `headerDistinctStates: 1` — the fixed header does **not** shrink, recolor, or transform
  on scroll. It is a static fixed bar. (Prompt 5: header is static; do not build a
  scroll transition the reference does not have.)
- `varying: 2` — two elements change state once, discretely: CSS transitions.
- `animatedElements: 13` out of ~2000 — hover transitions on buttons and cards.
- **No** GSAP, ScrollTrigger, Lenis, Locomotive, ScrollMagic, AOS, Swiper, or Framer. No
  `IntersectionObserver`. No scroll listeners. `libs: []`.

**Therefore `framer-motion` is not justified** (Appendix A requires the profile to say so
explicitly). CSS transitions cover everything here.

## 4. Content: static, no fetch, no auth, no geo

- Server-rendered Duda HTML, 421KB. `fetchAfterLoad: false` — no client data fetching, no
  loading or empty states to capture.
- `auth: false`, `geo: false`. Nothing behind a login or a geo gate.
- Third-party runtime present on the reference and **not** being cloned (D-15): Google
  reCAPTCHA (3 iframes), a fixed chat/CTA widget (`aside.ae-module`), a contact modal
  overlay, a fixed bottom bar. We ship no trackers, no chat, no captcha.

## 6. Type, color, and the CTA

- Display/headings: **Mohave** (self-hosted, hibu CDN). Body: **Lato**. Also loaded:
  Poppins (testimonial body), Open Sans, Schibsted Grotesk, Source Sans Pro, Kumbh Sans,
  Be Vietnam — 18 `@font-face` rules total. Mohave and Lato are the two that carry the page.
- Type scale @1440 → @390: H1 48 → 40, H2 40 → 30, H3 24 → 22, body 16, hero lede 20 → 18,
  quote 25 → 20. Headings are weight 400 (H1/H2) and 700 (H3), letter-spacing `normal`
  except the FAQ heading (-0.48px @1440 / -0.44px @390).
- Primary CTA: solid **`rgb(197, 23, 22)`**, radius 10px, 280×50 (40px in the header),
  Lato 16/400, no uppercase. It is the highest-chroma element on the page — the constraint
  Prompt 9 has to preserve.
- Reference defect we will **not** copy: CTA anchors compute `color: rgb(0,0,238)` (UA
  default link blue) on the red fill — a contrast failure. Ours is AA per D-19.

## 7. Measurement axes — capturing vs skipping

**Capturing** (this is a density / responsive / state problem, not a motion problem):

1. **Geometry** — per-section box, position, z-order, overflow, plus inner-grid child
   boxes normalized to the section origin.
2. **Static appearance** — color, background, background-image, resolved family, size,
   weight, letter-spacing, line-height, text-transform, opacity, borders, radius, shadow,
   padding, margin, display/flex/grid, gap, text-align. Per section, per heading, per
   paragraph.
3. **Responsive** — every pass at 390 / 768 / 1440.
4. **State-as-reference** — header at-top and engaged, drawer open and closed, and (from
   Prompt 6 on) form pristine/focus/error/submitted and accordion item-N-open.
5. **Structural metrics** for ADAPTED, **token conformance** for NOVEL.

**Skipping, with reason:**

- **Scroll-linked rAF traces as an ongoing axis** — the profile found zero scroll-linked
  motion. The trace ran once, proved the negative, and is archived. Re-running it per
  section would be the single largest artifact this harness can produce, for nothing.
- **Text-effect / split-library capture** — heading `span` counts are recorded per heading
  and are 0–2 (plain markup). No char/word splitting, no visually-hidden duplicate. Not an
  axis here.
- **Hover below 768** — per the cost rule.
- **430 and 600 and 1024** as diff breakpoints — recorded above, not captured.
- **Loading / empty states** — nothing is fetched; they do not exist.
- **Their carousel's timing** — one static slider, not load-bearing.

## 8. Harness

| script | what it does |
|---|---|
| `harness/config.mjs` | constants: reference, route→ref-page map, BP_SET, thresholds |
| `harness/lib.mjs` | browser, settle + animation freeze, section extraction, appearance capture, state capture, section screenshot |
| `harness/profile.mjs` | STEP A profiling, `--bp`, `--headed`, 2 concurrent |
| `harness/capture.mjs` | `--side ref\|ours --route --bp` (or `--all`), headless, writes `.harness/<side>/<route>-<bp>/`, 2 concurrent |
| `harness/motion.mjs` | rAF motion trace, `--px 3`, verdict line |
| `harness/tokens.mjs` | NOVEL token conformance against `app/tokens.css` (Prompt 5) |
| `harness/diff.mjs` | all three measurements, ranked table → `docs/divergence.md` |

Concurrency is 2 everywhere (MAX_AGENTS). Every pass prints one summary line and writes
its output to `.harness/`. `--route`/`--bp` mean a subagent can measure one section
without touching another agent's work.

Sections are screenshotted **by their own bounding box**, so comparison is
section-relative by construction — absolute `scrollY` is never used to align the two
sides, which matters because our page heights differ from theirs by design.

Note for Git Bash users: `--route /` is mangled by MSYS path conversion. Use
`MSYS_NO_PATHCONV=1` or `--all`.
